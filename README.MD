# Репозиторий backend по курсу "Разработка интернет-приложений"
## Лабораторная работа №3

Реализовать методы бэкенда для `аутентификации` и `регистрации`. Авторизация через хранение сессий. Автозаполнение пользователя в таблице `заявок` при создании новой. Добавить описание методов для `swagger`.

Добавить проверку `Permissions` для методов `модератора`. Без авторизации в `Swagger` должно быть доступно только чтение-получение данных через API, с авторизацией - методы `пользователя`, а для `модератора` доступны все методы.
